# hanji-parser · 한지

A Python library that turns Korean word-processor files (`.hwp`, `.hwpx`) into text an LLM can actually use.

```python
import hanji

doc = hanji.load("2026_business_plan.hwp")
print(doc.to_markdown())
```

## Install

Not on PyPI yet. Clone and install from source. Requires Python 3.10+.

```bash
git clone <repo-url> hanji
cd hanji
pip install -e .
```

## Usage

### Command line

```bash
hanji report.hwp                     # Markdown to stdout
hanji report.hwpx --text             # plain text
hanji report.hwp --html -o report.html
hanji *.hwp --chunks --size 600 > chunks.jsonl   # RAG chunks as JSON Lines
```

`python -m hanji ...` works the same way.

### Python

```python
import hanji

doc = hanji.load("press_release.hwp")   # path, bytes, or an open file

doc.title, doc.author                   # ('누리호 명칭 선정', '홍길동')
doc.to_text()                           # paragraphs separated by blank lines, table cells by tabs
doc.to_markdown()                       # headings, tables and footnotes
doc.to_html()                           # keeps rowspan / colspan

for table in doc.tables:
    print(table.grid())                 # [['항목', '2025', ''], ['매출', '상반기', '120'], ...]
```

### RAG chunks

```python
for c in doc.chunks(size=800, overlap=80):
    print(c.id, c.headings, c.text[:40])
# s0b3-7 ['1. 사업 개요', '1.1 추진 배경'] 국내 기업의 문서 작업 중 상당수가…
```

- A new chunk starts at every heading.
- `headings` holds the heading trail above the chunk. Prepending it to the text before embedding noticeably improves retrieval.
- `section`, `start` and `end` point back to the blocks in the original document.
- Tables are never split mid-row, so a single large table can exceed `size`.

### FastAPI

```python
from fastapi import FastAPI, HTTPException, UploadFile
import hanji

app = FastAPI()

@app.post("/parse")
async def parse(file: UploadFile):
    try:
        doc = hanji.loads(await file.read())
    except hanji.HanjiError as e:
        raise HTTPException(422, detail={"reason": e.reason, "message": str(e)})
    return {"title": doc.title, "markdown": doc.to_markdown()}
```

## Supported / not supported

- [x] HWP 5.0 (`.hwp`) and HWPX (`.hwpx`)
- [x] Body text, line breaks, tabs
- [x] Tables, including merged cells. Nested tables are flattened to text
- [x] Outline styles → heading levels
- [x] Footnotes and endnotes → `[^1]` markers + `doc.notes`
- [x] Text inside text boxes and shapes
- [x] Equations → `$...$` (Hancom equation syntax as-is, not LaTeX)
- [x] Title and author
- [ ] Images and charts (text only)
- [ ] Auto-numbering (numbers generated by styles, like `1.` or `가.`, are not emitted)
- [ ] HWP 3.x, password-protected documents, distribution documents

Unreadable documents raise `HanjiError`, with the cause in `e.reason`:

| `reason` | Meaning |
|---|---|
| `unknown-format` | Not an HWP/HWPX file |
| `hwp3` | Legacy HWP 3.x. Re-save it in Hangul as HWP 5.0 or HWPX |
| `encrypted` | Password-protected document |
| `distribution` | Distribution document (body text is encrypted by design) |
| `broken` | Damaged file or unexpected content |
